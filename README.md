# ChatGPT Sites 준비 프로젝트

이 폴더는 원래 Streamlit 앱을 지원 런타임 호환성을 확인하기 쉬운 정적 웹앱으로 옮긴 배포 후보입니다.

## 포함 파일

- `index.html`: 입력 폼과 결과/주의사항 화면
- `model.js`: 출생 시 국가 코드를 범주형으로 처리한 Logistic Regression 계수와 분류 로직
- `app.js`: 입력 폼과 대한민국 출생 시 국적 처리
- `build_model.py`: 로컬 원자료로 모델 계수를 다시 생성하는 스크립트

원본 조사자료, CSV, 노트북, 코드북은 포함하지 않았습니다. 이 앱은 2021년 조사 당시 기록 분류 데모이며 미래 귀화확률 예측용이 아닙니다.

Sites에서 지원되는 형태인지 확인해야 하며, 이 폴더 자체만으로 사이트가 배포되지는 않습니다.



## 모델 갱신

프로젝트 루트의 data20261020.csv로 build_model.py를 실행하면 model.js가 다시 생성됩니다. CSV는 배포 폴더에 복사하거나 GitHub에 올리지 마세요. 학습 대상은 rel_imm=1, birth_nat_1=2, 유효한 birth_nat_code가 있는 행입니다. 국가 코드는 숫자 크기가 아니라 범주형 값으로 학습합니다. 제공된 코드북에는 국가명 대응표가 없어 사이트에는 코드 숫자로 표시됩니다.
