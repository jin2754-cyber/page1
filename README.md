# ChatGPT Sites 준비 프로젝트

이 폴더는 원래 Streamlit 앱을 지원 런타임 호환성을 확인하기 쉬운 정적 웹앱으로 옮긴 배포 후보입니다.

## 포함 파일

- `index.html`: 입력 폼과 결과/주의사항 화면
- `model.js`: 현재 Logistic Regression 모델의 스케일링 값과 계수를 사용한 브라우저 내 분류 로직

원본 조사자료, CSV, 노트북, 코드북은 포함하지 않았습니다. 이 앱은 2021년 조사 당시 기록 분류 데모이며 미래 귀화확률 예측용이 아닙니다.

## ChatGPT Sites에서 진행

ChatGPT 데스크톱 앱의 Sites에서 이 프로젝트 폴더를 열고 호환성 검사를 요청합니다. 예시 요청:

> 이 프로젝트를 ChatGPT Sites에서 배포할 수 있는지 확인해줘. 호환되지 않는 부분이 있으면 현재 입력 항목, 분류 결과, 분석자료 표, 주의사항을 유지하면서 필요한 변경을 해줘. 먼저 배포 후보 버전을 저장해서 검토할 수 있게 하고, 공개 배포는 검토 후 진행해줘.

Sites에서 지원되는 형태인지 확인해야 하며, 이 폴더 자체만으로 사이트가 배포되지는 않습니다.
